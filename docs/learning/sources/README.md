# Learning sources

Curated, licence-checked source lists for the subjects the Arena's subject decks are built from. Every URL in these files was opened and verified on the date stated in the file. Deck authors read the per-topic list first and cite one source page per card using the attribution format given in each file.

Adding a subject: copy the structure of an existing file (how to learn, primary sources, free resources, practice material, deck authoring rules with a per-topic reading list, freshness), verify every URL, record licences, then write the deck.
